# Rotinas por etapa

| Etapa | Pasta | Linguagens |
| --- | --- | --- |
| Anomalias, filtro e padronização | [preprocess](preprocess/README.md) | R e Shell/CDO |
| Ajuste e projeção | [index](index/README.md) | R |
| Composições e monção | [analysis](analysis/README.md) | R e notebook Python |
| Diagramas/mapas | [plots](plots/README.md) | Python e GrADS |
| Funções compartilhadas | [functions](functions/README.md) | R, Python e GrADS |

Executar as rotinas a partir de INDEX_MIRISA ou configurar MIRISA_ROOT conforme a [configuração](../config/README.md). As funções puras não mudam o diretório de trabalho. Versões anteriores e protótipos estão em [experiments](../experiments/README.md).

Os nomes datados foram mantidos. A inclusão de uma rotina nesta pasta indica sua finalidade, não aprovação científica nem garantia de que todos os blocos executem. Consulta a [avaliação técnica](../AVALIACAO_TECNICA.md).
