# Resultados

`referencia/` contém os gráficos, métricas e metadados gerados com `exemplos/parametros.json`. A tabela temporal completa pode ser recriada executando o script; não é versionada na referência para evitar dados redundantes.

`local/` recebe novas execuções e é ignorado pelo Git. Fornece `--saida` para separar experimentos e evitar sobrescrever seus resultados anteriores.
