# Pesquisa

Espaço para organizar estudos, análises e materiais de reprodução de artigos desenvolvidos no projeto MIRISA, incluindo relações com índices de monção e precipitação.

As rotinas e análises existentes permanecem em [INDEX_MIRISA](../INDEX_MIRISA/README.md). Esta pasta foi criada para receber a organização das pesquisas.

Ao implementar índices de outros autores, documenta as referências originais, a autoria do código e eventuais adaptações metodológicas.
